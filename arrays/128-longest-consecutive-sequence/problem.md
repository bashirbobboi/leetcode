# Longest Consecutive Sequence

## Description
Given an unsorted integer array, find the length of the longest run of consecutive values. You must write an algorithm that runs in **O(n)** time.

## Example 1
- **Input:** `nums = [100, 4, 200, 1, 3, 2]`
- **Output:** `4`
- **Note:** Longest consecutive run is `[1, 2, 3, 4]`.

## Example 2
- **Input:** `nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]`
- **Output:** `9`
- **Note:** Distinct values form `0` through `8` consecutively; duplicate `0` does not change the length.

## Example 3
- **Input:** `nums = [1, 0, 1, 2]`
- **Output:** `3`
- **Note:** Distinct values are `{0, 1, 2}` — one consecutive block of length 3.
